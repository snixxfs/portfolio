Smart Trash Collector — IoT Waste Segregation Rover
Arduino · ESP8266 · Ultrasonic and Moisture Sensors · 3-DOF Robotic Arm · Li-ion + Solar
Built this for a semester project with my team. An IoT rover that figures out if waste is wet or dry using sensors, then sorts it automatically with a 3-DOF robotic arm. Runs on solar and Li-ion hybrid power. We got it to about 90% accuracy on the first real demo which honestly surprised us.
